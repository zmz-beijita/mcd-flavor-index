# 评价采集方法与口径

> 真香指数的全部原料。本文件说明评价从哪来、怎么收、怎么算，保证别人能复核。

## 采集目标

回答一个问题：**公开的真实用户评价里，大家怎么说某个麦当劳商品？**

不采集：外卖订单截图、官方广告文案、门店营销海报、AI 生成的评价。

## 采集来源

采集于 **2026-10-25**，六个公开平台：

| 来源 | 性质 | 典型内容 |
|---|---|---|
| 小红书 | UGC 笔记 | 「麦当劳汉堡测评｜到底哪个最值得点」类笔记，含分档推荐与避雷提示 |
| 什么值得买 | UGC 社区 | 美食板块的横向测评与排行榜，常给出分项评分与缺点 |
| 大众点评 | UGC 点评 | 单店实拍点评，含"口味：非常好"等结构化评分 |
| 微信公众号 | 美食测评号 | 单品深度测评，含「推荐指数 9 分 / 强烈推荐」等打分 |
| 今日头条 | UGC 图文 | 媒体与自媒体测评，批评往往更直白 |
| 现食研 | 独立食品测评 | 逐项拆解式测评，含重量克数与专业评分 |

## 采集口径

1. **评分采用各平台原生评分**（5 分制），不做二次折算、不做加权。
   - 小红书笔记里的 ⭐ 数量级 → 5 星
   - 什么值得买的分档（夯 / 顶级 / 金道行）→ 5 星；人上人 / NPC → 3 星
   - 现食研的「4.3 / 5」→ 4 星
   - 大众点评的「口味：非常好」→ 4 星（保守取值）
   - 公众号测评的「9 分 / 10」→ 5 星
2. **评价原文保留完整表述**，只做必要的截断，不改写语义。
3. **每条必须有可辨识的来源**，标注平台与账号类型。
4. **同一商品的不同评价分别计数**，不做去重（不同作者即不同样本）。
5. **不采信明显的营销号软文**（无实拍、无细节、全篇夸赞且带购买链接）。

## 采集方式

通过 WebSearch 检索公开可访问的 UGC 原文，逐条摘录评分与关键表述，
存入 `data_ugc.json`。

```json
{
  "name": "龙焰芝士棒鸡腿堡",
  "official_tags": ["浓郁奶香拉丝芝士", "韩式辣椒黄油风味", "上新"],
  "official_price_yuan": 29.9,
  "ugc": [
    {
      "score": 2,
      "text": "宣传图的拉丝完全是诈骗来的……",
      "source": "微信公众号测评"
    }
  ]
}
```

## 已知局限（必须如实告知使用者）

1. **样本量小**：当前基线 49 篇 / 9 个商品。n=4 的商品与 n=9 的商品（巨无霸）
   不能同等对待，页面上必须同时显示样本量与评分区间。
2. **平台偏差**：小红书与测评号用户对新品更敏感，评分天然更两极；
   大众点评偏日常消费、评分更集中。因此**离散度本身也带平台偏差**。
3. **时间集中**：全部采集于 2026-10-25，反映的是当季菜单。
   麦当劳菜单每日轮换，商品与评价对应关系会变。
4. **官方标签与评价不是同一时间线**：标签是接口当前值，评价是历史表述。
   本项目在页面上标注了采集日期，供使用者判断。
5. **不是随机样本**：采到的是能被检索到的公开评价，存在可见性偏差。

## 计算口径

```
真香指数   = 该商品全部真实评价评分的算术平均
评分离散度 = 该商品最高星 − 最低星
负面占比   = 评分 ≤ 3 的篇数 / 总篇数
官方标签落差 = 官方标签声称的效果，是否被真实评价中的否定表述命中
```

「官方标签落差」的判定规则是**关键词匹配**，规则公开在
`skills/mcd-flavor-index/scripts/flavor_index.py` 的 `CONFLICT_PATTERNS`，
不做黑箱。

## 复现方式

```bash
# 查看当前数据集
cat data_ugc.json

# 重新计算并查看派生指标
python skills/mcd-flavor-index/scripts/flavor_index.py --list
python skills/mcd-flavor-index/scripts/flavor_index.py --item 龙焰芝士棒
```

`data_ugc.json` 是纯文本、可 diff、可 review。任何人拿到它都能算出同样的真香指数——
这是本项目可信度的地基。
