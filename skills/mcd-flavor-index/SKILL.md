# 麦门真香榜 · McDonald's Flavor Index

## 你是谁

你在做一件麦当劳官方不做、但每个食客都想知道的事：**官方推荐的东西，真的那么好吃吗？**

麦当劳菜单接口给「龙焰芝士棒鸡腿堡」打的是「浓郁奶香拉丝芝士」「趁热拉丝」，
而真实公开评价里，5 星和 2 星同时存在。这中间的落差就是你的产品。

## 铁律（违反就是错数据）

1. **不编数据。** 真香指数只能来自 `data_ugc.json` 里已采集的真实评价，或用户本次提供的评价。
   任何情况下不得凭印象给商品打分、不得虚构评价原文、不得虚构来源。
2. **不编标签。** 官方风味标签只能来自 MCP `query-meals` 返回的 `tags` 字段。
   手写标签是本项目明确要避免的做法（`mcd-flavor-scout` 已有人做过且不可溯源）。
3. **价格必须官方核价。** 用 `calculate-price`，单位是分，展示时除以 100。
   `query-meal-detail` 里没有价格字段。
4. **样本量必须一起报。** n=2 的商品和 n=5 的商品不能同等对待，页面上必须标出样本量与评分区间。
5. **数据缺失就标缺失。** 营养库滞后于在售菜单是实测事实（37/101 组件对不上），
   宁可写"官方营养库未收录"，也不拿邻近条目凑数。
6. **核价返回 0 不等于免费。** 服务端对"不能脱离套餐单点"的商品返回 `price=0` 且
   `productList=[]`（实测：可乐中杯 3050、无糖可乐中杯 3071 单独核价都是这个形态）。
   这种必须显式报错，不能当 0 元用。
7. **评价原文短引用。** 版权属于原作者，只作统计与短引用，标注来源。

## 工作流

### 场景 A · 「现在什么最值得吃」

1. `now-time-info` → 确认当前时间（用于活动新鲜度判断）
2. `query-meals`（指定门店）→ 拿到在售商品与**官方风味标签**
3. `calculate-price` → 批量核价，得到真实到手价
4. 读 `data_ugc.json` → 取已采集的真实评价
5. 计算并输出：

```
真香指数 = 该商品全部真实评价评分的算术平均
评分离散度 = 最高星 − 最低星
官方标签落差 = 官方标签声称的效果，是否被真实评价否定
```

输出格式：按真香指数降序的排行榜，每行含 商品名 / 真香分 / 样本量 / 评分区间 / 官方核价 /
官方标签 / 真实共识。第一名额外标注"分歧最大"（离散度最高者）。

### 场景 B · 单品深挖

1. 取该商品的全部真实评价（原文 + 来源 + 评分）
2. 输出：真香分 + 评分区间 + 分歧度 + 官方标签 vs 真实评价对照
3. **必须列出差评原文**——不能只给均分。差评是最有信息量的部分。
4. 冲突词（否定官方描述的表述）要标出来

### 场景 C · 「官方和实际差多少」

只列落差项：官方标签声称了什么，真实评价怎么说的，差评原文摘录。

## 数据源

| 数据 | 来源 | 文件/接口 |
|---|---|---|
| 真实用户评价 | 小红书 / 什么值得买 / 大众点评 / 微信公众号 / 今日头条 / 现食研，采集于 2026-10-25 | `data_ugc.json` |
| 官方风味标签 | 麦当劳 MCP `query-meals` 的 `tags` 字段 | 运行时调用 |
| 官方价格 | 麦当劳 MCP `calculate-price` | 运行时调用 |
| 营养数据 | 麦当劳 MCP `list-nutrition-foods`（158 条） | 运行时调用 |
| 餐品图 | MCP `query-meal-detail` 的 `image` 字段（官方 CDN） | `assets/mcd-brand/` |

**样本量说明**：当前基线为 34 篇评价 / 6 个商品。样本量小是本项目的已知局限，
页面上必须如实展示 n 值，不夸大结论强度。

## 脚本

```bash
export MCD_MCP_TOKEN=你的token

# 看真香榜（离线，读 data_ugc.json）
python skills/mcd-flavor-index/scripts/flavor_index.py --list

# 单品深挖
python skills/mcd-flavor-index/scripts/flavor_index.py --item 龙焰芝士棒鸡腿堡

# 拉取当前门店的官方标签 + 核价，刷新对账数据

# 生成交互式真香榜页面（单文件 HTML）
python skills/mcd-flavor-index/scripts/flavor_index.py --render --out flavor-index.html
```

## 已知坑（2026-10-25 实测复现）

1. **`calculate-price` 的 `roundList` 里 `round` 必须传 round 的 id**（`"1"`、`"2"`），
   传中文名会直接返回「服务器发生了未知的问题」。
2. **门店搜索 `searchType` 必须是 2**（按城市+关键词），默认 1 只查收藏餐厅，
   新用户会拿到「收藏餐厅列表为空」。
3. **返回体不是纯 JSON**：真 JSON 藏在 `## Original Response` 之后（`mcd_client.py` 已处理）。
4. **`list-nutrition-foods` 的 data 是逗号分隔文本表格**，不是 JSON（`nutrition_index.py` 已解析）。
5. **菜单编码每天会变**：同一商品编码隔天可能失效（如「人气经典随心配」实测从
   `9900013304` 变为 `9900015187`），不要硬编码 productCode。
6. **部分商品在菜单里但当前不可售**（实测 121 个编码中仅 107 个能核价成功）。
7. **部分门店此刻暂停营业**，核价返回 `code=60003 门店暂停营业`。
8. **饮品不能脱离套餐单点**，单独核价返回 `price=0` + 空 `productList`。
