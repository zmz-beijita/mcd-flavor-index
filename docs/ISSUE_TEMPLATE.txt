项目名称：麦门真香榜 · McDonald's Flavor Index
项目地址：https://github.com/zmz-beijita/mcd-flavor-index
项目简介：官方菜单接口说「浓郁奶香拉丝芝士」，真实评价说「宣传图的拉丝完全是诈骗来的」。本项目把麦当劳官方风味标签（query-meals 返回的 44 种官方标注）与 22 篇真实公开用户评价摊开对账，算出真香指数、评分离散度与官方标签落差。官方标签来自 MCP 接口、每日自动更新、可溯源；评价原文带来源标注，差评必须给出。附免 Token 单文件交互页面（可点商品卡切换、评论区按好评差评筛选）与 8 条实测 MCP 踩坑记录。
