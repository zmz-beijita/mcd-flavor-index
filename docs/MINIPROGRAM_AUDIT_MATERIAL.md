## 三、审核备注（复制这段）

```
本项目为「麦当劳程序员创意开发大赛」参赛作品（作品名称：麦门真香榜），是纯查询与统计类工具，不含任何交易、下单、支付或内容社区功能。

【功能说明】
把麦当劳官方 MCP 接口返回的风味标签，与公开平台上的真实用户评价摊开对账，计算真香指数、评分离散度与官方标签落差。

【数据来源】
1. 官方侧：麦当劳中国官方 MCP 接口（mcp.mcd.cn），提供菜单、在售分类、风味标签、配料清单、套餐结构与官方核价，均为实时调用；
2. 口碑侧：49 篇公开可访问的用户评价，来源于小红书、什么值得买、大众点评、微信公众号、今日头条、现食研、新厨房、携程点评、新浪看点、搜狐美食等公开平台，每条均在页面内标注来源，差评同样展示，未做筛选。

【隐私与合规】
1. 不采集任何用户个人信息：未调用 wx.getUserInfo / getUserProfile / getPhoneNumber / getLocation 等隐私接口；
2. 不使用 wx.requestPayment 等支付能力，无下单、无会员储值、无商品交易；
3. 无诱导分享、无诱导关注、无强制关注公众号行为，未设置 open-type="share"；
4. 用户的投票与理由仅通过 wx.setStorageSync 保存在用户本机，不上传服务器、不与任何第三方共享，卸载即清除；
5. 小程序内所有数据均为包内预置的静态 JSON（/data/flavor.json），运行时不请求任何外部域名；
6. 页面底部与介绍中均已标注「非麦当劳官方产品 · 评价版权归原作者所有」。

【类目匹配说明】
本小程序为工具类信息查询与数据统计，不涉及交易、社交、医疗、教育、金融等需要特殊资质的类目，故选择「工具 → 信息查询」。

【相关说明】
本作品基于腾讯 WorkBuddy 开发，源码已开源至 GitHub：https://github.com/zmz-beijita/mcd-flavor-index
```

## 七、常见驳回原因与规避（自查用）

| 驳回原因 | 本项目是否涉及 | 说明 |
|---|---|---|
| 类目与功能不符 | ❌ 不会 | 已选「工具 → 信息查询」，功能是查询统计 |
| 涉及诱导分享/关注 | ❌ 不会 | 无 `open-type="share"`、无 `onShareAppMessage` |
| 收集用户信息未声明 | ❌ 不会 | 零隐私接口调用 |
| 支付/交易类功能 | ❌ 不会 | 无 `wx.requestPayment`，无下单入口 |
| 页面内容违规 | ⚠️ 注意 | 简介和备注里都写了「非麦当劳官方产品」 |
| 功能无法正常运行 | ⚠️ 注意 | 上传前务必在开发者工具真机跑一遍 4 个页面 |
| 名称涉及他人商标 | ⚠️ 注意 | 「麦门真香榜」是原创名；**不要用「麦当劳」三个字做小程序名** |

> ⚠️ **最后一条特别重要**：小程序名称**不能蹭「麦当劳」的商标**。
> 「麦门真香榜」没问题，但如果起名「麦当劳真香榜」会被投诉下架。
> 名称一年只能改 3 次，想清楚再填。
