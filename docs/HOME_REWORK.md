## 关键设计决策

### 双榜结构
```
真香榜（6 个有真实评价的商品）
  按真香指数排序，每条显示：排名 / 真香分 / 样本量 / 评分区间 / 官方标签 / 分歧标记
  ↓ 点条目就地展开：官方介绍 + 官方标签 vs 真实共识 + 评分离散度 + 评价原文 + 投票区

人气榜（76 个门店在售商品）
  按官方标签信号排序（人气/爆款/上新/粉丝之选/限时特惠）
  标注：是否已有真实评价 → 有则显示真香分，无则显示"待评价"
```

### 官方介绍的三个来源（都是 MCP 真实数据）
1. **官方风味标签** — `query-meals` 的 `tags` 字段（已有）
2. **官方配料清单** — `query-meal-detail` 的 `modification.values[].name`（巨无霸酱/吉士/生菜/酸黄瓜/洋葱粒）
3. **官方产品描述** — `campaign-calendar` 里对应活动的 `content`（如"韩式辣酱碰撞青梅，裹挟黄油香气"）

### 排行榜条目的信息密度
一行放不下所有信息，所以设计成：
- **常驻**：排名 / 商品图 / 名称 / 真香分（大字）/ 样本量 / 区间
- **展开态**：官方介绍 / 官方标签 vs 真实共识 / 离散度条 / 评价原文 / 投票区

## 改造后首页结构

```
Hero（标题 + 副标题 + 三按钮：看真香榜第1 / 看人气榜 / 写评价）
  ↓
统计条（最低真香分 / 真实评价样本 / 在售商品数 76）
  ↓
【真香榜】6 个 · 按真香指数排     ← 主体
  ↓
【人气榜】76 个 · 按官方信号排     ← 覆盖全量
  ↓
数据来源说明
```

## 验证要求

- 6 商品 × 3 筛选 × 展开/收起，零 undefined、零溢出
- 375 窄屏验证
- 投票 → 投稿 → 立即出现在评论区顶部
- 商品总数从 76 个数据校验通过
