# 麦门真香榜 · 微信小程序版

> 官方菜单接口说「浓郁奶香拉丝芝士」，真实评价说「宣传图的拉丝完全是诈骗来的」。
> 小程序版把这两个账摊开，并且**让你也能投一票、写一句理由**。

麦当劳程序员创意开发大赛参赛作品 · 非麦当劳官方产品

---

## 三个 Tab

| | 做什么 | 借鉴自 |
|---|---|---|
| **真香榜** | 6 个在售商品的真香指数、评分离散度、官方标签 vs 真实共识对账 | — |
| **麦门广场** | 陌生人的投票理由流，可按「真香 / 踩雷」筛选 | 「钱包请等等」的广场机制 |
| **我的** | 我投过的票（只存本机） | — |

## 核心机制：投票 + 理由

从「钱包请等等」学到的最重要一件事：**光有点赞不够，要让人写理由。**

它的爆款理由是「买了让我看看」「生小外星人了分我一个」——**带梗的理由才会被传播**。
麦门这边天然就有自己的梗：

> 「宣传图的拉丝完全是诈骗来的」
> 「两根没有奶酪的芝士棒在麦当劳值三块钱」
> 「芝士棒是空心的，只有面粉皮子」

所以小程序的问法不是「该不该买」（用户没这动机），而是：

> **「这顿你觉得值不值？」** → 真香 / 一般 / 踩雷 + 一句理由（≤60 字）→ 发到麦门广场

## 数据来源

| 内容 | 来源 |
|---|---|
| 官方风味标签 | 麦当劳 MCP `query-meals` 的 `tags` 字段（44 种官方标注） |
| 真实评价 | 34 篇公开 UGC（小红书 / 什么值得买 / 大众点评 / 微信公众号 / 今日头条 / 现食研 / 新厨房） |
| 价格 | 麦当劳 MCP `calculate-price` 官方核价 |

`data/flavor.json` 是预置数据，与 GitHub 版 `mcd-flavor-index` 的 `data_ugc.json` 同源。

## 运行

### 本地预览

在微信开发者工具里导入本目录（`appid` 用 `touristappid` 即可游客模式预览）。

### 目录结构

```
mcd-flavor-mp/
├── app.js / app.json / app.wxss
├── project.config.json
├── data/
│   └── flavor.json              # 预置榜单数据（6 商品 / 34 篇评价）
├── assets/
│   ├── icons/                   # tabBar 图标
│   └── food-*.png               # 官方商品图（MCP image 字段）
├── utils/
│   └── flavor-store.js          # 数据层：读榜单、投票、投稿、广场流
└── pages/
    ├── index/index.*            # 真香榜
    ├── detail/detail.*          # 详情 + 投票 + 写理由
    ├── square/square.*          # 麦门广场
    └── profile/profile.*        # 我的
```

## 技术要点

- **纯原生微信小程序**，零 npm 依赖、零云服务
- 交互数据（投票 / 投稿）存 `wx.setStorageSync`，**不上传**，本机可见
- 预置数据用 `wx.request` 读本地 `data/flavor.json`
- 商品图来自 MCP `query-meal-detail` 返回的官方 CDN 地址
- 图标为纯 Python 手写 PNG（无第三方图形库）

## 隐私与合规

- 不采集任何用户身份信息，不需要授权
- 投票与投稿仅存本地存储
- 评价原文版权归原作者所有，仅作短引用与统计并标注来源
- 非麦当劳官方产品，不构成对任何商品的评价或推荐
